# marble-native-linux

Reproducible kernel and platform bring-up for Redmi Note 12 Turbo (`marble`).

Current scope is limited to:

- M0: private repository, pinned sources, reproducible CI
- M1: clean Android Common Kernel/GKI baseline build

No flashing, AVB changes, repartitioning, KernelSU integration, dual-boot selector,
hardware forward-porting, overclocking, or performance tuning is part of M0/M1.

See the M0/M1 bring-up branch and its pull request for the active work.
